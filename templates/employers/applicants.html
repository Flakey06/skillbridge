How Skill Compatibility Works

Close

Skill Compatibility is calculated automatically when the candidate applies. It compares evidence saved in the candidate profile and résumé with the requirements of that specific job.

  1. Skill coverage (70 points): recruiter-weighted skills found in the profile or selected résumé.
  2. Evidence (30 points): projects, internships, and self-declared skills, using the recruiter’s evidence priorities.

The result is saved with the application on a scale of 0–100, so recruiters see the same submission-time assessment even if the candidate later edits their profile.

The minimum compatibility filter now uses this automatic score. Recruiters can still complete a separate structured evaluation from the candidate detail page.
